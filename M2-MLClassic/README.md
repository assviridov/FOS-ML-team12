# Модуль 2. Классические методы машинного обучения с учителем и настройка моделей


Модуль включает восемь учебных практикумов и завершается одной самостоятельной работой № 2. Эта работа объединяет изученные модели в единую сравнительную экспериментальную схему на двух индивидуальных датасетах.

| **Учебные практикумы** | УП 4–11 |
| **Компетенция** | ML-3; MF-3; ML-2 |
| **Индикаторы** | ML-3.1; ML-3.2; MF3.1; ML-2.1; ML-2.3 |
| **Самостоятельная работа** | СР № 2 |
| Датасеты | Два индивидуальных датасета: регрессия и классификация |
| **Вес СР** | 25% |
