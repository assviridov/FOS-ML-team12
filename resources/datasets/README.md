# Датасеты для курса «Машинное обучение»

В этом каталоге собраны описания всех наборов данных, используемых в лабораторных и самостоятельных работах дисциплины. Каждый файл содержит детальную информацию о структуре данных, признаках, целевых переменных и предполагаемых задачах машинного обучения.

## Общая информация

Дисциплина «Машинное обучение» (Б1.В.12) охватывает следующие типы задач:
- **Классификация** (бинарная и многоклассовая)
- **Регрессия**
- **Кластеризация**
- **Поиск аномалий**
- **Ассоциативный анализ**

Датасеты подобраны из различных предметных областей: телеком, финансы, медицина, ритейл, производство, логистика, энергетика, образование и другие.

## Формат описаний

Каждый файл с описанием датасета содержит следующие разделы:

- **Идентификаторы и контекст** – поля, не используемые в модели, но необходимые для трассировки.
- **Признаки** – описание всех входных переменных (тип, единицы измерения, смысл).
- **Целевая переменная** – описание целевого поля (тип задачи).
- **Дополнительные поля** – если присутствуют предсказания других систем (для бенчмаркинга).

## Использование

Все датасеты предназначены для образовательных целей. Данные являются синтетическими или анонимизированными, не содержат реальной персональной информации.

При выполнении лабораторных работ следуйте инструкциям преподавателя по использованию конкретных наборов данных.
